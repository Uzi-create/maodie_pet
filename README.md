# 圆头耄耋桌宠 MVP

一只透明、置顶、会乱动，还会对你阴阳怪气的 Windows/macOS 桌宠。它很小，脾气倒是不小。😼

## 已实现

- 透明、无边框、默认始终置顶
- 左键拖拽时切换哈气姿态并左右挣扎，松手回弹
- 单击切换到完整哈气姿态，并自动回到待机
- 自动随机散步，散步期间播放爬行动画
- 自动巡查频率可切换为 10 秒、1 分钟、2 分钟、5 分钟或暂停
- 蜘蛛形态加大显示，爬行时带方向速度线和扬尘
- 动态“桌面小舞台”：柔和桌垫、落地影、微光，以及轮换出现的爪印、飞蛾和困意符号
- 暖色漫画聊天气泡，带阴影和指向老吴的气泡尾巴
- “老吴查账”读取 Codex 计划、5 小时/周额度、重置时间和累计 token
- 右键菜单：切换置顶/桌面小舞台、随机动作、巡查频率、老吴查账、退出
- 系统托盘：显示/隐藏、随机动作、巡查频率、老吴查账、切换桌面小舞台/置顶、退出
- 多显示器边界约束
- 素材缺失或损坏时自动绘制一只可见的占位橘猫

## 运行环境

- Windows 10/11 或 macOS 12 及更新版本
- Python 3.9 或更新版本
- “老吴查账”为可选功能，需要本机安装并登录 Codex 桌面端

## 首次安装

在本目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

推荐直接双击：

```text
启动桌宠.bat
```

也可以在 PowerShell 中启动：

```powershell
.\run.ps1
```

激活虚拟环境后，也可以直接运行：

```powershell
python app.py
```

### macOS

在 Finder 中双击 `run-macos.command`。第一次运行会自动创建 `.venv` 并安装依赖，之后直接启动桌宠。

也可以在终端运行：

```bash
chmod +x run-macos.command build-macos.command
./run-macos.command
```

需要生成可双击的独立应用时运行：

```bash
./build-macos.command
open "dist/圆头耄耋.app"
```

生成结果位于 `dist/圆头耄耋.app`。首次打开若被 Gatekeeper 阻止，请在 Finder 中右键应用并选择“打开”。

## 角色素材

程序主要使用下面三个素材：

```text
assets/
├── idle-sprite-v4.png # 参考哈气动作调色后的透明待机姿态
├── crawl.gif          # 原梗蜘蛛爬行动画
└── hiss-sprite.png    # 补全后的哈气姿态
```

两张姿态图使用真正的透明通道；爬行动画来自原始 GIF 的逐帧去白底。程序保持宽高比缩放。

降级顺序也安排好了，免得少一张图整只猫就当场罢工：

1. 待机优先加载 `idle-sprite-v4.png`，再依次尝试 `idle-sprite-v2.png`、`idle-sprite.png` 和旧版 `idle.png`。
2. 两张待机图都缺失或损坏时，尝试读取有效 GIF 的第一帧作为待机图。
3. 所有素材都不可用时，显示程序绘制的占位橘猫。
4. 某个动作素材缺失或损坏时，该动作仍保留气泡和窗口反馈，角色画面退回待机图。

## 操作

- 左键拖动：移动桌宠
- 左键单击：哈气一次
- 右键：打开功能菜单
- 单击或双击托盘图标：显示/隐藏桌宠
- 右键菜单“老吴查账（Codex）”：显示 20 秒的 Codex 猫账本
- 右键菜单“桌面小舞台”：随时隐藏或恢复动态布景
- 右键或托盘菜单“巡查频率”：选择每 10 秒或 1/2/5 分钟巡查一次，也可暂停自动巡查

退出请使用桌宠右键菜单或托盘菜单里的“退出耄耋”。只把窗口关掉时，如果系统托盘可用，它会躲进托盘继续暗中观察。
